# shikimori-goida2

Репозиторий: <https://github.com/VovaBurry/shikimori-goida2>

Тема для [Shikimori](https://shikimori.one) в двух вариантах — светлая `goida2.css` и тёмная `goida2_black.css`; картинки и шрифты для них лежат в `assets/`.

## Что внутри

| Файл | Назначение |
| --- | --- |
| `goida2.css` | Светлая тема — её и вставляют на Shikimori |
| `goida2_black.css` | Тёмная тема — альтернатива, вставляется вместо светлой |
| `goida2.txt` | Исходник обеих тем (правки делаем здесь) |
| `assets/` | Ассеты, на которые ссылается тема: тайл-фон Monster, курсор-банка, гиф-аватарка, тянка в углу, обложка профиля, шрифты Lato / Oswald / Comfortaa в `woff2` |
| `tools/build.js` | Сборка обеих тем из `goida2.txt` с переводом ссылок на raw-URL репозитория |
| `legacy/` | Черновики: `style.css`, `goida.css`, `Csss.css`, `iloveyuuko.css`, `pinky_style_blocked.css`, `style.min.css`, `style_formatted.txt` |
| `sr/`, `niz/` | Исходники ассетов (не подключены к теме): обложки, фон без конверта, видео-заготовки для гифки |

Тема оформляет: фон с банками Monster, курсор-банку, гиф-аватарку и обложку профиля, тянку в углу, верхнее меню с выпадающими списками аниме/манги, карточки активности и график, статистику, друзей, клубы, избранное и мобильную вёрстку.

## Установка

1. Откройте **Профиль → Настройки → Внешний вид → Свой CSS** (Shikimori).
2. Выберите светлую или тёмную версию:
   - светлая — содержимое `goida2.css`;
   - тёмная — содержимое `goida2_black.css`.
3. Скопируйте выбранный файл целиком (только его, не оба), вставьте в поле и сохраните.
4. Обновите страницу профиля (`Ctrl+F5`).

Тёмная версия — самостоятельный файл: тот же фон, курсор, аватарка, тянка, шапка и меню, но фон страницы и карточек почти чёрный, текст светлый. Вставлять `@import` с `goida2.css` не нужно — Shikimori применяет один CSS.

## Как подключаются картинки

CSS не хранит картинки внутри, а подтягивает их из этого репозитория по `raw.githubusercontent.com`:

```css
background: url("https://raw.githubusercontent.com/VovaBurry/shikimori-goida2/main/assets/avatar.gif") center / cover;
```

Так работают все 12 ссылок: `monster-bg-tile.jpg`, `monster-cursor-32.png`, `monster-pointer-32.png`, `catgirl-corner.gif`, `profile-cover.jpg`, `avatar.gif`, шесть файлов шрифтов.

Что важно:

- **Репозиторий должен оставаться публичным** — raw-ссылки на приватный репозиторий не отдаются без токена.
- Если переименуете аккаунт или репозиторий, ссылки сломаются. Поправьте их пересборкой (см. ниже) и закоммитьте оба CSS.
- Меняете картинку — кладём файл в `assets/` с тем же именем, менять CSS не нужно. Новое имя файла — обязательно обновите `goida2.txt` и пересоберите.
- GitHub кеширует raw до нескольких минут; после пуша обновите страницу с `Ctrl+F5`.

## Как вносить правки

Правим `goida2.txt`, затем пересобираем CSS (обе темы сразу):

```bash
node tools/build.js
```

Только одна тема: `node tools/build.js --light` или `node tools/build.js --dark`.

Другие адрес и ветка:

```bash
node tools/build.js --owner my-login --repo my-repo --branch master
```

Скрипт также перекодирует текст в UTF-8: исходник `goida2.txt` сохранён в CP866, и без перекодировки кириллица в комментариях и в `content:` выглядела бы мусором.

### Как устроена тёмная тема

`goida2_black.css` собирается из того же `goida2.txt`. В `tools/build.js` есть список пар «светлый цвет → тёмный» (`DARK_COLORS`) плюс небольшой блок стилей поиска в шапке. Скрипт печатает, сколько пар применилось: если после правки `goida2.txt` какая-то пара перестала находиться, её выведут в отчёте — значит цвет в исходнике изменился и пару надо обновить.

Добавили новый цвет в `goida2.txt` — проверьте, не нужна ли для него своя пара, и запустите сборку:

- фон страницы `#F8F7F9` → `#121212`;
- фон карточек `#FFFFFF` → `#1A1A1A`;
- текст `#4A4A4A` → `#D6D6D6`;
- рамки `#EAEAEA` → `#2A2A2A`;
- акцент `#D84C51` → `#E85A60`.

CSS руками не редактируем — в шапке файлов есть напоминание, а пересборка перезапишет изменения.

## Замечания

- Внешних зависимостей нет: шрифты локальные (`woff2`), Google Fonts и imgur/fastpic не используются.
- Тема рассчитана на десктопную вёрстку Shikimori; для экранов уже 1023px есть блок `@media` в конце файла (тянка в углу скрывается, шапка профиля сжимается).
- Тёмная тема перекрашивает только то, что задаёт сама тема. Блоки, которые Shikimori рисует своим оформлением и тема не трогает, могут остаться светлыми — их правки добавляются в `tools/build.js` отдельным блоком.
- Лицензий на картинки и шрифты в репозитории нет: шрифты свободные (OFL), картинки — материалы автора темы. Если тема публикуется, проверьте права на арты заранее.
